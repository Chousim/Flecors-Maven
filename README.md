# [cite_start]Flecors - Sistema Web de Catálogo e Inventarios [cite: 176, 179]

## 📌 Descripción del Proyecto
[cite_start]Flecors es una Web API robusta con un catálogo interactivo diseñado para tiendas de ropa americana[cite: 180, 181]. [cite_start]El objetivo principal es centralizar el inventario y profesionalizar la exhibición de los productos, permitiendo a los clientes ver el stock real y conectar directamente con los vendedores para aumentar las ventas[cite: 180, 182].
